01 / HOW_I_THINK

BREAK IT DOWN.
FIND THE WHY.
FIX THE THING.

I learn best by getting inside a problem: observe it, isolate the failure, test a change, then verify what actually worked.

  • laptop imaging + hardware troubleshooting
  • code, Bluetooth + servo tuning
  • simulation, signals + image analysis
observe → isolate → test → verify
01

Observe

Look closely, gather details, and notice what changed.

02

Isolate

Narrow the issue to the root cause instead of guessing.

03

Test

Try one clear change at a time and compare the result.

04

Verify

Confirm the fix, document it, and use it to improve the next version.

My default loop: notice the issue → narrow it down → test a fix → document what actually worked.
