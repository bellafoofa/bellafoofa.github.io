# Isabella Chandler Portfolio

Clean, light-green Biomedical Engineering portfolio for GitHub Pages.

## Upload
Upload the contents of this folder to the root of your `USERNAME.github.io` repository.

Keep the `assets` folder structure intact. The project images are referenced with relative paths such as `assets/projects/nuitlume/preview.png`, so they will work on GitHub Pages as long as the folder names are unchanged.

## Resume
Put your resume PDF at `assets/resume.pdf`.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
