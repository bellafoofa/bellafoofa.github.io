Company-Sponsored Senior Project

Mopec Senior Design Project

I’m part of Lawrence Tech’s BME company-sponsored senior project with Mopec. Our team is developing, training, and fine-tuning an AI model intended for future use in healthcare settings such as hospitals, medical facilities, and related gross pathology workflows.

The project is still in its early phase, so the current work is centered on building a strong foundation. That includes reviewing available datasets, planning how training, validation, and testing should be structured, and creating an organized workflow that can support later benchmarking and evaluation.

Focus

AI workflow planning, gross pathology analysis, and dataset strategy.

What I’m building

Early-stage workflow structure, dataset review, and a foundation for future model tuning and evaluation.

Skills shown

AI workflow planning, technical documentation, teamwork, and healthcare-minded systems thinking.

Wearable Technology

SyncCare

SyncCare is a wellness wearable concept built around privacy-aware emotional support. The concept pairs a wearable interface with AI analysis and a companion app to provide simple, user-friendly wellness feedback.

Goal

Create a calm, approachable tool that translates captured user input into supportive insights.

Project themes

Wearable UX, healthcare AI concepts, privacy, and user-centered system design.

Skills shown

Concept development, interface thinking, healthcare framing, and communication of technical ideas.

Embedded Systems

Smart Collar

This project combines a pet activity-tracking wearable with an automated feeder concept. Activity data collected through the collar can be shared through BLE communication to trigger a physical feeding response.

Core idea

Connect wearable sensing to a simple, tangible outcome using a low-cost embedded system.

Main components

Circuit Playground Bluefruit boards, BLE communication, and servo-based feeder control.

Skills shown

CircuitPython, embedded prototyping, wireless logic, iteration, and physical system integration.

Bioinstrumentation

HeadUp

HeadUp is a posture-focused wearable designed to detect sustained head-down posture and encourage correction. It explores how sensing and simple feedback can support healthier study or work habits.

Design direction

Comfortable posture support with technical feedback that feels useful instead of overwhelming.

Engineering themes

Sensing, calibration, threshold logic, prototyping, and basic user testing.

Skills shown

Prototype fabrication, device concept development, testing, and communication of results.

Biomechanics Concept

Pressure-Point Insole

This concept explores a smart insole designed around pressure mapping, support, and comfort. The idea centers on identifying high-pressure areas and using that information to improve user experience and foot support.

Goal

Support comfort and pressure awareness through a wearable product concept.

Design themes

Pressure redistribution, supportive cushioning, smart sensing, and product visualization.

Skills shown

Concept ideation, biomedical framing, product communication, and design refinement.

Human-Computer Interaction

Presence Plant

Presence Plant is a soft, ambient desk companion that communicates focus and availability in shared spaces. Instead of a harsh notification system, it uses a playful plant-like form to make presence cues feel more natural and friendly.

Core idea

Translate status, focus, and presence into a physical object with more personality.

Project themes

Ambient communication, playful interaction design, and calm technology.

Skills shown

Concept development, systems thinking, visual communication, and user-centered framing.
